# Code of Conduct

Micron OS adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies in every project space: issues, pull
requests, discussions, and any chat or event run for the project.

## In short

- Be welcoming and respectful, whatever someone's experience, background or
  identity.
- Give and accept constructive feedback gracefully. Critique code, not people.
- No harassment, insults, sexualised language or imagery, trolling, or
  publishing others' private information.

## Reporting

Report unacceptable behaviour privately to **prashant.arbat@gmail.com**. All
reports are reviewed promptly and handled confidentially. Maintainers will
follow the Contributor Covenant's enforcement guidelines (correction, warning,
temporary ban, permanent ban) according to the impact of the behaviour.
