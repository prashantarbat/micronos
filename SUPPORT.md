# Getting help with Micron OS

Micron OS is a fully open-source **Community Edition** under the Apache
License 2.0. Every feature is free. For organisations that need guaranteed
response times or someone to run their firewalls, paid services are available
around the same software.

## Community help (free)

| Where | Use it for |
| :--- | :--- |
| [Documentation](docs/) | Installation, hardening, module reference |
| GitHub **Discussions** | Questions, how-to, sharing configurations |
| GitHub **Issues** | Reproducible bugs and feature requests (use the templates) |
| [SECURITY.md](SECURITY.md) | Vulnerabilities: report privately, never in an issue |

Community help is best-effort, from maintainers and other users, with no
response-time commitment. Security fixes are always released to the Community
Edition.

Paid services never unlock extra features. They add guarantees, people and
convenience on top of the same open-source code.
